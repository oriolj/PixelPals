# Submarine Safari

A couch co-op pixel-art game for a parent and small kids. A little yellow
submarine explores a glowing reef: dad steers, the 5-year-old photographs
every creature for the family album, and the 2-year-old flashes the lights
so the shy ones come out to dance.

| Seat | Who | Does | Pad | Keyboard |
|---|---|---|---|---|
| 1 Pilot (blue) | the grown-up | swims (with inertia), pings the sonar to find hiders | left stick / d-pad, A = sonar, Start = pause | WASD, Shift = sonar, Esc = pause |
| 2 Camera (yellow) | a 5-year-old | points the viewfinder up/right/down/left and snaps | stick or d-pad, A = snap | arrow keys, Enter = snap |
| 3 Lights (green) | a 2-year-old | flashes the lights in a new colour; 3 quick = disco | any button | Space or any other key |

- Nobody can lose: rocks only boing, an empty photo is a bubble, a shell, a
  smiling rock or a starfish. A dive lasts 6 minutes, or ends early when all
  12 species were photographed, then the sub surfaces into a sunset and the
  album shows today's photos.
- Twelve species: clownfish, blue tang, pufferfish, turtle, seahorse; the
  crab, octopus and eel hide until a sonar ping or a flash; the jellyfish,
  anglerfish, squid and lantern fish live in the dark trench and only come
  out while the lights shine. The whale passes once per dive near the top.
- After 40 s without a new photo, a trail of pearls leads to one.
- Fewer players: with nobody on the camera it snaps by itself; with nobody
  on the lights they flash by themselves.
- Pause: the pilot's Start (Esc). In the pause, B (Q) goes back to joining.
- Join screen: the Camera's B (Backspace) opens the album to browse (left /
  right turn to the whale page). **Parent reset**: the pilot holds Start + B
  (Esc + Q) for 3 seconds and the album is emptied.

The album is saved in Godot's user folder
(`~/.local/share/godot/app_userdata/Submarine Safari/album.json`), never in
the repo, and holds only which species were found.

## Run it

```
make setup    # once: pinned Godot 4.7.2 + GUT, Python deps via uv
make start    # play
make demo     # watch it play itself (with its own demo album)
make help     # everything else (tests, assets, frame captures, export)
```

Art is generated by `make sprites` (Endesga 32, linted), the map by `make
reef` and the sounds by `make sfx`. See [CLAUDE.md](CLAUDE.md) for the
architecture and contracts, and [PLAN.md](PLAN.md) for the design.
